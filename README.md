# Cloud Evidence Collection

This repository contains a simple evidence collection layout for AWS resources and deployment assets.

## Structure

- `site/` — static website assets
- `ec2/` — EC2-related evidence and notes
- `lambda/` ��� Lambda-related evidence and notes
